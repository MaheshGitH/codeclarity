# 🎙️ CodeClarity

CodeClarity is an interactive interview preparation tool that helps developers practice explaining code out loud and receive instant feedback on their communication skills. Perfect for preparing technical interviews where articulating your thought process is just as important as writing code.

## 🎯 Purpose

To help developers master technical communication by providing a platform to practice explaining code with AI-powered feedback. Many developers excel at writing code but struggle to articulate their thought process during interviews - CodeClarity bridges this gap.

## 🚀 Features

- Record yourself explaining code snippets naturally
- Real-time speech-to-text transcription
- AI-powered feedback on clarity, structure, and delivery
- Code syntax highlighting for multiple languages
- Interview simulation environment

## 🛠️ Built With

- Next.js
- TypeScript
- Tailwind CSS
- Groq SDK (AI)
- React Syntax Highlighter
- Bun
